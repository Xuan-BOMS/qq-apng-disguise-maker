# QQ APNG 伪装图制作器

一个离线运行的单文件工具，用两张图片制作“双面 PNG”：普通 PNG 预览显示静态封面，支持 APNG 的查看器显示另一张画面。适合制作 QQ 聊天图片中“预览和点开原图不同”的效果，也可用于其他支持 APNG 的场景。

## 点击即用

**[打开在线制作器](https://xuan-boms.github.io/qq-apng-disguise-maker/)**

页面通过 GitHub Pages 提供，图片只在浏览器本地处理，无需上传到服务器。也可以下载仓库中的 [`index.html`](./index.html)，直接双击离线使用。

## 操作方式

1. 在“静态封面”中选择聊天预览时希望显示的图片。
2. 在“打开后画面”中选择点开图片后希望显示的图片。
3. 按需选择“完整显示”或“填满裁切”；完整显示时可调整留白颜色。
4. 点击“生成 PNG”，在成品预览中确认默认显示的画面，再点击“下载完整 PNG”。
5. 将下载的文件发送到 QQ 等支持该效果的客户端测试。

“拆分已有 APNG”可上传做好的双面 PNG，分别预览并下载静态封面和不同的动画画面。重复的保持帧会自动略过。

输出采用静态封面的像素尺寸。建议使用新版 Chrome 或 Edge；封面上限为 1600 万像素。

## 原理与兼容性

生成的文件是 APNG：PNG 的默认静态图像作为封面，动画帧放入打开后画面，并附带 `ChatBarApngDisguise=1;STATIC;1` 文本标记。这个结构与示例 QQ 图片一致。

不同 QQ 版本、其他聊天软件和图片查看器对 APNG 的处理可能不同。发送时应保留原始 PNG 文件；平台重新压缩或转换格式后，双面效果可能消失。请以目标客户端的实际显示结果为准。
